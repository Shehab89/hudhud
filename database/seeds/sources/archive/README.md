# Archived registry (not loaded)

These files are the earlier, broad registry (241 outlets, October 2026). Hudhud now
monitors a small curated universe (see `../SCHEMA.md`). The archive is kept because its
feed checks, ownership notes and newsroom research are reused by curated records with the
same `id`, and as a record of what was considered. `hudhud seed` does not read this folder;
sources that were seeded from it earlier are marked `archived` and stop being collected.
